# S3918

Warning: The style allows {max} `New` per block; this is one more

Under `{"maxNewPerBlock":N}`, each `New` past the Nth in one method body, label body or
`{ }` block; a nested block counts its own. IRIS runs any number of them; gather the names into
one `New a, b`.

IRIS compiles the example. Checked with the style `{"maxNewPerBlock":1}`.

```objectscript
ROUTINE Demo.NewPerBlock
Report
    New count
    New total //! S3918
    Set count = 3, total = 10
    Write count, " items, total ", total, !
    Quit
```
