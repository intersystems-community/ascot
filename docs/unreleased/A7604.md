# A7604

Error: Label '{label}' has no formal parameter list, so $$ cannot call it (IRIS: <PARAMETER>); `{label}()` would make it a function

`$$Label` calls a label as a function, which a label is only when it declares a formal
parameter list, even an empty `()`. `Do Label` reaches any label, but `$$` of a bare one
compiles and raises `<PARAMETER>` when it runs. Give the label a parameter list, or call it
with `Do`.

IRIS compiles the example, and `do Main^Demo.Labels` raises `<PARAMETER>` when it runs.

```objectscript
ROUTINE Demo.Labels
Greet
    Write "hi", !
    Quit
Main
    Write $$Greet() //! A7604
    Quit
```
