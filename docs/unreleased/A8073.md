# A8073

Error: Syntax error {scope}: {detail}

A method body that doesn't parse, the rest of it going unchecked, or an argument default
that is neither a literal nor an expression in `{braces}`; a label's default must begin
with a literal. IRIS refuses to compile the document. The message names the mistake where
it is clear, such as an unknown command or a function given the wrong arguments, and
otherwise lists what could come next at that point; correct the marked line.

IRIS rejects the example.

```objectscript
Class Demo.InvalidSyntax
{

ClassMethod Greet(name As %String)
{
    Wrte "Hello, ", name, ! //! A8073
}

}
```
