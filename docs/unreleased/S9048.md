# S9048

Warning: Put {wanted} between `}` and `{keyword}`

Under `{"closeBrace":{"newlineAfter":false}}`, an `Else`, `ElseIf` or `Catch` on the line
below the `}` it follows; under `true`, one on the brace's line, `} Else {`. IRIS accepts either
layout; move the keyword.

IRIS compiles the example. Checked with the style `{"closeBrace":{"newlineAfter":false}}`.

```objectscript
Class Demo.ChainBreak
{

ClassMethod Sign(n As %Integer) As %Integer
{
    If n < 0 {
        Quit -1
    }
    Else { //! S9048
        Quit 1
    }
}

}
```
