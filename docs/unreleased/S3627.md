# S3627

Warning: Put {wanted} before `}`

Under `{"closeBrace":{"newlineBefore":true}}`, a block's `}` on the line of its last command,
`Set y = 1 }`; under `false`, one on a line of its own. IRIS accepts either layout; move the
brace.

IRIS compiles the example. Checked with the style `{"closeBrace":{"newlineBefore":true}}`.

```objectscript
Class Demo.CloseBraceBreak
{

ClassMethod Sign(n As %Integer) As %Integer
{
    If n < 0 {
        Quit -1 } //! S3627
    Quit 1
}

}
```
